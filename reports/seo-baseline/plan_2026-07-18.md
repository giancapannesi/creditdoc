# CreditDoc SEO Ranking Plan — 2026-07-18 → 2026-10-10 (12 weeks)

**Scope:** Multi-month ranking climb. Built on the 2026-07-18 baseline. Measurement-first, intervention-second.

**Context that shapes the plan:**
- Tools + `/answers/` pages have been submitted for indexing recently — data should update over next 2-4 weeks
- 6-week-old domain, still building trust with Google
- Content pipeline is paused by founder — don't restart at old pace
- Watcher deploys per-slug within 5 min — no rebuild latency
- Bing collapsed post-migration; fingerprint fixes shipped 2026-07-16

## Guiding rules (from prior session lessons)

1. **Never bulk-rewrite titles or metas** — Google needs 7d+ per page to measure. Bulk change = starts the clock over site-wide.
2. **Measure before you move.** No intervention on a page family until we have 4 weeks of data proving it's stuck.
3. **Small batches, watch, iterate.** 5-page batches, 14d observation window, then next batch.
4. **Do not restart aggressive content generation.** Content-cron freeze stays until we prove existing pages can rank.
5. **Every intervention has a rollback plan.** Watcher makes rollback = git revert + 5 min.

## What's OFF the plan (deliberately)

- Bulk title/meta changes — banned
- New content generation at prior pace — founder mandate
- Author bio / E-E-A-T signals — rejected
- Schema restructuring (AggregateRating etc.) — already deployed, working
- Big design overhauls — traffic problem is upstream (Google not surfacing us), not CRO
- Bing paid indexing — free lane running via cron already

## Weekly rhythm

- **Monday:** GSC pull + week-over-week diff (existing cron `gsc_weekly_pull.py` Mon 07:30 UTC)
- **Wednesday:** review the week's strike-zone position moves
- **Friday:** decide next batch OR next diagnostic OR hold

## Reversibility

Every content edit rolls back via `git revert` + watcher redeploys within 5 min. No commit is "stuck."
